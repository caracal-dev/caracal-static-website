It replaces the usual round of driver installers, permission dialogs, and utility apps.

Verification

Verify the ISO before you install it.

Download the ISO and the matching checksum into the same folder, then run the command for your image.

sha256sum -c caracal-latest-amd64.iso-CHECKSUM sha256sum -c caracal-nvidia-latest-amd64.iso-CHECKSUM

If switching with `rpm-ostree rebase` instead of using the ISO, verify the container image with Cosign.

cosign verify --key cosign.pub ghcr.io/caracal-dev/caracal:latest

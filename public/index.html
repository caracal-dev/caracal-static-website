Why Caracal

Linux audio that actually works, without a week of configuration.

Moving from Windows shouldn't mean trading one set of headaches for another. Caracal is built so your audio interface, plugins, and DAW are ready on day one — and the system itself stays reliable over time.

Ready on day one

Plug in and record. No configuration rabbit holes.

On Windows, getting low-latency audio often means fighting ASIO drivers, buffer settings, and background processes. Caracal arrives already configured for music production — your audio interface works, your latency is low, and you can start a session without touching a single setting.

Lean studio base

The essentials are installed. The bigger catalog is one click away.

Ardour, Qtractor, Carla, Hydrogen, Wine/Yabridge, and a focused plugin set are included out of the box. REAPER, Renoise, Bitwig, Mixbus, extra synths, and larger plugin collections live in the bundled Caracal Software Installer so the base system stays lean.

Focused plugin base

Start with a practical plugin set, then add exactly what you need.

Caracal preinstalls LSP, Calf, Guitarix, Vitalium, DISTRHO DrumSynth/EQuinox, and Carla integration. The installer expands that into Dragonfly Reverb, Surge XT, Cardinal, Decent Sampler, BYOD, AIDA-X, Neural Amp Modeler, TAL plugins, Zam, DPF, and more.

Your Windows plugins come with you

Run your existing VST library, not just Linux alternatives.

Caracal includes built-in support for running Windows VST plugins on Linux. If you have a plugin library from your Windows setup, you don't have to leave it behind — most plugins load and run without any extra steps.

A system that stays stable

Updates can't break your studio setup.

Unlike a traditional Windows or Linux install, Caracal's system files are locked — apps and updates can't quietly corrupt the foundation your studio runs on. Every system update is applied as a clean snapshot, and if an update causes problems, you can boot back into the previous version in seconds.

Workflow

From a blank session to a finished mix, without leaving Linux.

Whether you're building tracks, recording live instruments, or running a plugin-heavy mix, Caracal covers the whole workflow — including the Windows VST plugins you already own.

What's included

A lean production base out of the box, with a much larger catalog ready to install.

Caracal now keeps the base image focused: the audio system, core DAWs, compatibility tools, and a practical plugin set are ready immediately. The larger DAW, synth, effect, and utility catalog is delivered through the custom software installer so you can add what you actually use.

Software installer

Add more software without hunting the internet for it.

The Caracal Software Installer gives you a curated catalog of DAWs, instruments, effects, and utilities. It has a desktop GUI, a terminal UI, install/uninstall actions, installed-state detection, and queueing so you can set up multiple tools in one pass.

Already on Fedora Atomic? Switch in place:

01

Switch to Caracal

If you're already on a compatible Fedora Atomic desktop, one command switches you over to Caracal. Alternatively, install a Fedora Atomic image first, then switch.

rpm-ostree rebase ostree-unverified-registry:ghcr.io/caracal-dev/caracal:latest
02

Run the first-time setup

A single command sets up everything your audio interface needs — low-latency permissions, Windows plugin support, and a few quality-of-life tweaks.

ujust first-run
03

Add your software

Open the bundled software installer to browse, queue, install, and uninstall DAWs, instruments, effects, and utilities. Or install individual apps with the focused helpers.

ujust software-installer

What You’ll See

Our custom setup wizard.

When you log into Caracal for the first time, you will be greeted with our custom setup wizard. First you can update your username and password if you choose or leave them as they are, then you get a straightforward first-run window that automatically configures the handful of things Caracal needs for audio work and points you toward the software installer for optional DAWs, instruments, effects, and utilities.

If you are coming from Microsoft Windows, this is the part that replaces the usual round of driver installers, permission dialogs, and utility apps.

Verification

Verify the ISO before you install it.

Download the ISO and the matching checksum file into the same folder, then run the command for the image you downloaded.

sha256sum -c caracal-latest-amd64.iso-CHECKSUM sha256sum -c caracal-nvidia-latest-amd64.iso-CHECKSUM

If you're switching with `rpm-ostree rebase` instead of using the ISO, advanced users can still verify the published container image with Cosign.

cosign verify --key cosign.pub ghcr.io/caracal-dev/caracal:latest
